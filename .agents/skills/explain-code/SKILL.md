# Explain Code

Leia os documentos relevantes em `.ai/` e inspecione o código citado e as camadas diretamente conectadas.

Explique do geral para o específico: requisição, validação, regras, persistência, resposta e falhas. Separe comportamento executável de exemplos comentados e intenção documentada. Use exemplos curtos quando ajudarem e aponte onde o código confirma cada afirmação.

Não edite código em uma tarefa somente de explicação. Termine destacando decisões, riscos ou lacunas ainda não definidos.
