# Contexto do projeto

O Vintex é uma prova de conceito de marketplace de moda circular para brechós e microempreendedores de moda usada, desenvolvido na disciplina AGES no semestre 2026/2 para um cliente real.

Este repositório cobre a API backend. O front-end e recursos de IA vivem em outros repositórios ou serviços.

O projeto está em estágio inicial: atualmente expõe `GET /health`; os arquivos de usuário contêm exemplos comentados, não uma funcionalidade entregue. A API deve evoluir a partir de requisitos confirmados e contratos explícitos.

Tecnologias observadas: Python 3.12, FastAPI, SQLAlchemy 2, PostgreSQL, Alembic, Pydantic Settings, Pytest, Ruff, Black e Docker.
